# Карта зависимостей

## 13. Карта основных стандартных зависимостей

```text
                   БАЗОВЫЕ

Сила ──────────────────────────────┐
                                  ↓
                              Боевая сила
                                  ↓
Усталость ───────────────────→ сила удара ↓


Здоровье ────────────────────→ боевое здоровье


Харизма первого + Множитель арены первого ──→ Динамическая поддержка первого ──→ Инициатива первого ──┐
                                                                                                      ├─→ Вероятность следующего действия
Харизма второго + Множитель арены второго ──→ Динамическая поддержка второго ──→ Инициатива второго ──┘


Тип арены ──────────────────────────────────→ Перки ──→ Изменение правил боя


Действия
   ↓
Усталость
   ↓
Инициатива ↓


Поддержка
   ↓
Возможное влияние на итоговые последствия


Здоровье = 0 ───────────────→ Поражение


Победа / поражение ─────────┐
Здоровье и ранения ─────────┼─→ вероятностный итог: жизнь / гибель
Поддержка и перки ──────────┘                     травма / без травмы


                 ПЕРКИ

могут вмешиваться в любую точку схемы
```

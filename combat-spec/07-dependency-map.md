# Карта зависимостей

## 13. Карта основных стандартных зависимостей

```text
                   БАЗОВЫЕ

Сила ──────────────────────────────┐
Временные эффекты ─────────────────┤
Стартовые травмы ──────────────────┤
                                  ↓
                              Боевая сила
                                  ↓
Усталость ───────────────────→ сила удара ↓


Здоровье ────────────────────┐
Временные эффекты ───────────┼─→ начальное боевое здоровье
Стартовые травмы ────────────┘


Харизма первого + предбоевые модификаторы + Множитель арены первого ──→ Динамическая поддержка первого ──→ Инициатива первого ──┐
                                                                                                      ├─→ Вероятность следующего действия
Харизма второго + предбоевые модификаторы + Множитель арены второго ──→ Динамическая поддержка второго ──→ Инициатива второго ──┘


Тип арены ──────────────────────────────────→ Перки ──→ Изменение правил боя


Действия
   ↓
Усталость
   ↓
Инициатива ↓


Поддержка
   ↓
Возможное влияние на итоговые последствия


Здоровье = 0 ───────────────→ Поражение


Лимит шагов достигнут
        +
Нет победителя ─────────────→ Ничья


Победа / поражение / ничья ─┐
Здоровье и ранения ─────────┼─→ вероятностный итог: жизнь / гибель
Поддержка и перки ──────────┘                     травма / без травмы


                 ПЕРКИ

Постоянные перки / временные эффекты / травмы
могут вмешиваться в любую точку схемы через общий hook-конвейер
```

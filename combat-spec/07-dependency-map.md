# Карта зависимостей

## 13. Карта основных стандартных зависимостей

```text
                   БАЗОВЫЕ

Сила ──────────────────────────────┐
Оружейный комплект ────────────────┤
Комплект доспехов ─────────────────┤
Временные эффекты ─────────────────┤
Стартовые травмы ──────────────────┤
                                  ↓
                              Боевая сила
                                  ↓
Усталость ───────────────────→ сила удара ↓


Здоровье ────────────────────┐
Временные эффекты ───────────┼─→ начальное боевое здоровье
Стартовые травмы ────────────┘


Харизма первого + предбоевые модификаторы + Множитель арены первого ──→ Динамическая поддержка первого ──→ Инициатива первого ──┐
                                                                                                      ├─→ Вероятность следующего действия
Харизма второго + предбоевые модификаторы + Множитель арены второго ──→ Динамическая поддержка второго ──→ Инициатива второго ──┘


Тип арены ──────────────────────────────────→ Перки ──→ Изменение правил боя


Класс бойца ─────────┬─→ допустимый weaponSet
                     ├─→ допустимый armorSet
                     └─→ матрица классов ─→ стартовая сила и инициатива

weaponSet ───────────┬─→ числовые модификаторы
                     ├─→ обязательный классовый приём
                     └─→ 1–2 дополнительных перка для rare / named

armorSet ────────────┬─→ числовые модификаторы
                     └─→ ровно 1 дополнительный перк для rare / named


Действия
   ↓
Усталость
   ↓
Инициатива ↓


Поддержка
   ↓
Возможное влияние на итоговые последствия


Здоровье = 0 ───────────────→ Поражение


Лимит шагов достигнут
        +
Нет победителя ─────────────→ Ничья


Победа / поражение / ничья ─┐
Здоровье и ранения ─────────┼─→ вероятностный итог: жизнь / гибель
Поддержка и перки ──────────┘                     травма / без травмы


          МОДИФИКАТОРЫ АРЕНЫ

Оружейные приёмы / перки снаряжения / постоянные перки / временные эффекты / травмы
реализуют `BattleModifier` и могут вмешиваться в любую точку схемы
через общий hook-конвейер
```
